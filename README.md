# Raccoon's CS2 Autoexec.cfg ♡

My personal Counter-Strike 2 config file
Mostly jump binds, quick utility drops, radar tweaks, performance stuff, and my current crosshair setup.
Super minimal, no bloat, just things that make the game feel better without messing with defaults too much.

## What's Inside

- Mouse sensitivity & jump binds (mwheel + space)
- Weapon/grenade binds + quick bomb drop alias
- HUD & radar (hold N for bigger radar boost)
- FPS/performance tweaks (300 fps cap, gamma)
- Quick disconnect, voice toggle, hand switch
- My exact crosshair commands (small, no outline, bright green)

Everything is grouped with // comments so it's easy to read or tweak.

## How to Install

1. Download `autoexec.cfg` from this repo (or copy the contents).
2. Place it in your CS2 cfg folder:  
   Usually:  
   `C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`  
   (or Linux/Mac equivalent)
3. (Recommended) Add this to your CS2 launch options in Steam:  
   `+exec autoexec`  
   Or just open console (~) in-game and type `exec autoexec` once.
4. Restart CS2 – it should load automatically on next launch!

If it doesn't load, make sure the file is named exactly `autoexec.cfg` (no .txt at the end) and is plain text.
